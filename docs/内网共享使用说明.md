# 林清轩 · 种草智能体 — 内网共享使用说明

## 一、给同事的访问方法

1. 确保与部署电脑连接**同一个网络**（同一 WiFi 或公司内网）
2. 浏览器打开：**http://192.168.0.106:5210**
3. 即可使用全部功能：达人筛选、蒲公英链接直达查询、品牌匹配评估、合作笔记外溢进店、**笔记互动查询（小红书/抖音）**

> 注意：IP 地址可能变化。若无法访问，请联系管理员确认最新 IP。

## 二、给管理员的操作手册

### 2.1 启动 / 停止

> **推荐：守护部署（服务永不掉线）**——崩溃自动拉起 + 随时可用：

```bash
cd LinQingXuan-Agent
./deploy/install.sh        # 一键安装守护（推荐，启动后终端可关闭，服务不中断）
./deploy/stop_guard.sh     # 停止守护（服务保持运行）
./deploy/uninstall.sh      # 完全卸载守护
# 状态查看: ./deploy/start_guard.sh（重复运行是幂等的，可随时执行）
```

守护循环每 8 秒检查一次 5210/9350/4000 三个端口，**任何服务崩溃都会在几秒内自动拉起**（已实测：强杀后端 4 秒内自愈）。日志在 `logs/guard.log`。

**备选：手动启动模式**（前台运行，按 Ctrl+C 停止）：

```bash
cd LinQingXuan-Agent
./start.sh        # 一键启动（自动拉起 Edge 无头实例 + Node 数据服务 + 后端）
# 按 Ctrl+C 停止
```

> ⚠️ 注意：若守护已运行，`./start.sh` 会提示「守护模式已运行」并直接退出，避免双实例冲突。

启动成功后终端会显示本机访问地址和同事访问地址，并提示各依赖服务的启动状态。

### 2.2 首次使用前检查（一次性）

| 检查项 | 方法 |
|---|---|
| 蒲公英 cookies 是否配置 | `grep -c PGY_COOKIES Spider_XHS/.env` 应输出 ≥1 |
| 蒲公英 cookies 是否过期 | 打开 http://localhost:5210 → 若达人查询报登录失效，需更新 `Spider_XHS/.env` 中的 `PGY_COOKIES` |
| **小红书 cookie（COOKIES）** | `grep -c '^COOKIES=' Spider_XHS/.env` 应输出 ≥1（笔记互动查询的小红书数据依赖） |
| **抖音 cookie（DY_COOKIES）** | `grep -c '^DY_COOKIES=' Spider_XHS/.env`（抖音视频互动查询需要，可选） |
| Edge 是否安装 | `/Applications/Microsoft Edge.app` 必须存在（合作笔记抓取依赖） |
| Node 服务 | 端口 4000（抖音互动数据依赖，start.sh 自动拉起） |
| macOS 防火墙 | 系统设置 → 网络 → 防火墙 → 若开启，需允许 Python 接受传入连接，否则同事无法访问 |

### 2.3 依赖清单

| 依赖 | 用途 | 缺失后果 |
|---|---|---|
| Python 3（含 flask/requests 等） | 后端服务 | 无法启动 |
| Microsoft Edge | CDP 无头抓取合作笔记/外溢进店 | 仅「合作笔记明细」「外溢进店中位数」不可用 |
| `Spider_XHS/.env` 的 `PGY_COOKIES` | 蒲公英平台数据接口鉴权 | 所有蒲公英功能不可用 |
| **`Spider_XHS/.env` 的 `COOKIES`** | 小红书笔记互动查询（点赞/评论/转发/收藏） | 「笔记互动」的小红书查询不可用 |
| **`Spider_XHS/.env` 的 `DY_COOKIES`** | 抖音视频互动查询 | 「笔记互动」的抖音查询不可用（小红书不受影响） |
| Node 服务（feishu-douyin-tool，端口 4000） | 抖音视频 ID 解析与互动数据 | 抖音互动查询不可用 |
| 可选 `LLM_API_KEY` | 大模型精评（默认 DeepSeek 兼容接口） | 自动降级为纯规则评分 |

## 三、笔记互动查询功能说明

### 3.1 使用方式

1. 打开智能体 → 顶栏「📎 笔记互动」标签页
2. 粘贴**小红书或抖音的笔记/视频链接** → 点击「🔍 查询互动数据」
3. 页面展示：标题、作者、封面、**点赞 / 收藏 / 评论 / 转发** 四个数据、标签、原文链接
4. **批量查询（推荐）**：输入框支持多行，**每行粘贴一条链接**，一次最多 50 条。粘贴后点「查询互动数据」，页面会实时显示进度（第 x/50 条），完成后表格汇总展示，支持 **📥 导出 CSV** 方便二次处理
5. 单条查询失败不影响其他条：失败行会显示原因（通常是链接凭证过期，从小红书 App 重新复制链接即可）

### 3.2 链接格式要求

| 平台 | 支持的链接 | 说明 |
|---|---|---|
| 小红书 | `https://www.xiaohongshu.com/explore/xxx?xsec_token=...`、`https://xhslink.com/xxx` 短链 | **必须带 xsec_token**（从 App「分享 → 复制链接」获取的完整链接自带）。仅复制浏览器地址栏 URL 可能缺少 token 而无法查询 |
| 抖音 | `https://v.douyin.com/xxx/`、`https://www.douyin.com/video/xxx` | 视频需为公开可见状态 |

> 小红书提示「链接缺少访问凭证」时：请在小红书 **App 内打开该笔记 → 分享 → 复制链接**，再粘贴查询。

### 3.3 Cookie 获取方法（管理员配置一次，长期有效）

**小红书（写入 `COOKIES`）：**
1. 电脑浏览器（Edge/Chrome）打开 https://www.xiaohongshu.com 并**登录账号**
2. 按 `F12` 打开开发者工具 → 切到 **Network（网络）** 标签
3. 刷新页面 → 在请求列表中点击任意一条 `www.xiaohongshu.com` 的请求
4. 在右侧 **Request Headers（请求标头）** 中找到 `Cookie:` 一栏，**复制整行值**（形如 `abRequestId=...; a1=...; web_session=...; ...`）
5. 编辑 `Spider_XHS/.env`：
   ```
   COOKIES='<粘贴的完整 Cookie 值>'
   ```
6. 重新执行 `./start.sh`

**抖音（写入 `DY_COOKIES`）：**
1. 浏览器打开 https://www.douyin.com 并登录账号
2. `F12` → Network → 刷新 → 点任意请求 → 复制 `Request Headers` 里的整行 `Cookie:` 值
3. 编辑 `Spider_XHS/.env`：
   ```
   DY_COOKIES='<粘贴的完整 Cookie 值>'
   ```
4. 重新执行 `./start.sh`

> Cookie 过期后查询会报错，重新按上述步骤更新即可。页面右上角/笔记互动页会显示「小红书已配置 / 抖音未配置」状态。

### 3.4 常见问题

**Q：小红书查询报「链接缺少访问凭证」**
- 该链接没有 xsec_token，请从 App「分享 → 复制链接」重新获取

**Q：抖音查询报「需要登录 Cookie」**
- 未配置 DY_COOKIES，按 3.3 步骤配置后重启

**Q：报「Cookie 已失效」**
- 账号登出/过期了，重新按 3.3 获取并更新 Cookie

## 四、常见问题（通用 FAQ）

**Q1：同事打不开 http://192.168.0.106:5210**
- 确认同事与你在同一网络（可互相 ping 通）
- 确认你电脑的防火墙放行了 Python（见 2.2）
- 确认服务在运行：`curl http://localhost:5210/api/pgy/status`

**Q2：查看合作笔记报「Edge 调试实例未运行」**
- 重新执行 `./start.sh`（会自动拉起 Edge）
- 或手动验证：`curl http://127.0.0.1:9350/json/version`

**Q3：端口 5210 被占用，start.sh 报错**
```bash
lsof -ti:5210 | xargs kill
./start.sh
```

**Q4：达人数据报登录失效/无权限**
- 蒲公英 cookies 过期，更新 `Spider_XHS/.env` 的 `PGY_COOKIES` 后重启

**Q5：电脑休眠/重启后服务没了**
- 唤醒/重启后重新执行 `./start.sh` 即可（Edge 与后端会一并拉起）

## 五、安全须知

- 本服务**未设访问密码**（按需求），仅限可信同事使用，请勿将链接外发给外部人员
- 蒲公英 cookies 保存在后端环境变量中，若链接流出内网，任何拿到地址的人都可使用你的蒲公英品牌账号数据，请知悉风险
- 后端已关闭 debug 模式（`debug=False`），避免 Werkzeug 调试器远程代码执行风险
