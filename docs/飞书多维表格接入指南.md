# 飞书多维表格接入指南

> 林清轩种草智能体 → 飞书多维表格 数据同步配置教程（约 5 分钟）

## 一、整体架构

```
┌─────────────────────────────┐         ┌──────────────────────┐
│  林清轩种草智能体 (localhost:5210)  │         │                      │
│  达人筛选 / 笔记采集 / 内容生成 / 销售分析│────────▶│  飞书多维表格        │
│        │  feishu_service 封装        │  REST  │  达人库 / 笔记库     │
│        └────────────────────────────┘   API  │  内容库 / 销售快照    │
└─────────────────────────────┘         └──────────────────────┘
```

- 智能体在后端封装了飞书开放平台的 **bitable REST API**
- 只需配置 4 个参数，即可把采集/生成/分析结果一键写入飞书表格
- 字段会自动创建（达人昵称、粉丝数、报价、外溢进店……无需手动建列）

## 二、获取 4 个配置参数

### 第 1 步：创建企业自建应用（拿 App ID / App Secret）

1. 打开 [飞书开放平台](https://open.feishu.cn/app)（需用管理员/开发者账号登录）
2. 点击 **创建应用 → 企业自建应用**，填名称（如「林清轩种草助手」）、图标
3. 创建后进入应用详情页
4. 左侧菜单 **「凭证与基础信息」**
5. 复制 **App ID**（形如 `cli_xxxxxxxxxxxxxxxx`）和 **App Secret**（形如 `xxxxxxxxxxxxxxxxxxxxxxxxxxxx`）

> ⚠️ App Secret 只显示一次，务必立即复制保存。

### 第 2 步：开通多维表格权限并发布

1. 左侧菜单 **「权限管理」**
2. 搜索并开通以下权限：
   - `bitable:app`（查看多维表格）
   - `bitable:app:readonly`（查看多维表格数据）
   - `bitable:record:write`（多维表格数据读写）—— 如找不到则开通「多维表格全部读写权限」
3. 左侧菜单 **「版本管理与发布」** → **创建版本** → **申请发布**
4. 等待管理员审核通过（自己审核的话，进入 [飞书管理后台](https://feishu.cn/admin) → 应用管理 → 审核通过）

### 第 3 步：创建多维表格（拿 App Token / Table ID）

1. 在飞书里新建一张 **多维表格**（文档 → 新建 → 多维表格），命名为「种草达人库」
2. 打开表格，复制浏览器地址栏链接，格式如下：

```
https://xxxxx.feishu.cn/base/bascnXXXXXXXXXXXXXXXX?table=tblXXXXXXXXXX&view=vewXXXXXXXX
```

| 参数 | 位置 | 示例 |
|---|---|---|
| **App Token** | `/base/` 后面 | `bascnXXXXXXXXXXXXXXXX` |
| **Table ID** | `?table=` 后面 | `tblXXXXXXXXXX` |

> 建议建 4 张表：达人库、笔记库、内容库、销售快照 —— 每张表只需填一次 Table ID。
> 如果只建一张表，所有数据都会写入同一张表（不同模块的字段会自动追加）。

## 三、在智能体中配置

1. 打开智能体页面 → **「⚙️ 设置」** Tab → 找到 **「📘 飞书多维表格同步」** 卡片
2. 填入 4 个参数：
   - **App ID** ← 第 1 步复制
   - **App Secret** ← 第 1 步复制
   - **多维表格 App Token** ← 第 3 步复制
   - **数据表 Table ID** ← 第 3 步复制
3. 点击 **💾 保存配置**
4. 点击 **🔌 测试连接**，显示「连接成功」即完成 ✅

## 四、使用方式

| 页面 | 操作 | 写入飞书内容 |
|---|---|---|
| 📣 达人筛选 | 搜索后点结果区右上角「📘 同步到飞书」 | 达人昵称/粉丝/互动/报价/外溢进店/标签 |
| 📱 小红书采集 | 搜索后点结果区右上角「📘 同步到飞书」 | 笔记标题/作者/点赞/收藏/评论/链接 |
| ✍️ 内容生成 | 生成文案/脚本后点「📘 同步到飞书内容库」 | 平台/主题/标题/正文 |
| 📈 销售分析 | 点「📘 同步销售快照到飞书」 | 销售总额/黑金霜占比/件数/周期快照 |

## 五、常见问题

**Q: 测试连接失败提示「App ID / App Secret 校验失败」**
→ 检查凭证是否复制完整；应用是否已发布且审核通过。

**Q: 提示「App Token / Table ID 校验失败」**
→ 检查链接中参数是否复制完整；确认当前登录的飞书账号对该表格有编辑权限。

**Q: 同步时报「权限不足」**
→ 到开放平台 → 权限管理，确认 bitable 相关权限已开通并**重新发布版本**。

**Q: 字段顺序不对 / 想加自定义字段**
→ 同步会自动创建固定字段；自定义分析可在飞书表格里手动加列，不受影响。

**Q: Cookie 失效了怎么办**
→ 蒲公英/小红书 Cookie 会定期失效，按浏览器 Network 面板重新复制即可（见智能体设置页提示）。
