# 飞书达人素材下载插件 — 导入与使用指南

> 配套智能体：林清轩黑金霜种草智能体（http://localhost:5210）
> 插件地址：`http://localhost:5210/plugin/`

## 一、插件能做什么

在飞书多维表格里，粘贴金山文档（kdocs.cn）的**达人素材分享链接**（每行一个），
插件会自动：

1. 渲染分享页 → 提取表格内嵌的素材图片（仅取真实素材，自动过滤 WPS 稻壳水印）
2. 下载原图 → 上传到飞书云盘
3. 写入当前多维表格（自动创建「素材名称 / 来源链接 / 素材图片 / 同步时间」字段）
4. 已发布过的链接自动跳过，不重复

## 二、导入步骤（1 分钟）

1. 打开你的飞书多维表格（任意一张）
2. 点击表格右上角 **「多维表格插件」** 图标（网格+魔方图标）
3. 在弹窗底部点击 **「自定义插件」**
4. 点击 **「+ 新增插件」**
5. 填写：
   - **插件名称**：`达人素材下载器`
   - **服务地址**：`http://localhost:5210/plugin/`
6. 点击 **确定** → 插件出现在列表中，点它即可打开使用

> ⚠️ 前提：本机智能体（端口 5210）必须处于运行状态。
> 建议使用**飞书桌面客户端**打开表格（网页版也可，但要求能访问本机 localhost）。

## 三、使用方法

1. 打开插件面板
2. 在输入框中粘贴素材链接，每行一个（支持完整链接或纯 link_id）：
   ```
   https://www.kdocs.cn/l/ciWu4bGOl9as
   https://www.kdocs.cn/l/cpK40zlY6XQU
   ```
3. 点击 **「⬇ 开始下载素材」**
4. 等待处理日志跑完（每个链接约 10~30 秒），刷新表格即可看到素材记录

### 目标表格说明

- 插件默认把素材发布到**智能体「飞书配置」里设置的表格**
  （当前为「小红书作者数据测试」表，App Token `ZVfKbmtXRa7K28sz3C3cKMM3nyh`）
- 如果想发布到**当前打开的其它表格**，在插件的「目标表格」栏手动填入该表的
  App Token 和 Table ID（地址栏 `base/` 后、`table=` 后的值）
- 传入了新表格后，后续同步也会写入新表格（配置被切换）

## 四、技术说明

| 项目 | 说明 |
|---|---|
| 插件载体 | 智能体 Flask 路由 `GET /plugin/`，返回单页 HTML（无外部依赖） |
| 后端接口 | `POST /api/kdocs/fetch`（批量处理）、`POST /api/kdocs/render`（单独渲染） |
| 素材来源 | kdocs 分享页 JS 渲染后 DOM 中的 `weboffice.ks3-cn-beijing.wpscdn.cn/shapes/*` |
| 上传方式 | 飞书 drive `medias/upload_all` → 附件字段（type=17）写入 |
| 去重 | 每次发布前查询表格中「来源链接」列，已存在则跳过 |
| 本地缓存 | 渲染 DOM：`/tmp/kd_html/{link_id}.html`；原图：`/tmp/kd_mat/{link_id}/` |

### 代码位置

- 插件页面：`backend/plugin.html`
- 素材处理服务：`backend/utils/kdocs_service.py`
- 接口路由：`backend/app.py`（`/api/kdocs/fetch`、`/api/kdocs/render`、`/plugin/`）
- 素材字段定义：`backend/utils/feishu_service.py`（`MATERIAL_FIELDS`）

## 五、常见问题

- **插件面板空白/无法加载**：确认智能体在运行；飞书客户端访问本机需允许 localhost。
- **提示「页面渲染失败/无缓存」**：该链接分享页可能需登录或已失效；插件后端会尝试
  Edge 无头渲染，本机环境下若失败可稍后在智能体侧手动补齐缓存。
- **想导入到其它多维表格**：把目标表的 App Token / Table ID 填进插件「目标表格」栏。
